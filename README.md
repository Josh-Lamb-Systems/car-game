# Apex Velocity

A cinematic Monaco street-circuit F1 game built with Three.js and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Controls

- `WASD` / arrow keys — accelerate, brake, steer
- `Space` — nitro boost
- `Shift` — drift
- `Esc` — pause

Choose between three cars with different speed, acceleration, and handling characteristics. The entire world, vehicle models, lighting, particles, and scenery are generated in code with Three.js.

## Race systems

- Closed, elevation-changing Monaco-inspired circuit with named sectors, harbor, tunnel, hairpin, swimming pool, and Rascasse sections
- Grip-limited cornering, tire degradation, aerodynamic drag, braking, understeer, wall impacts, drift, and nitro
- Seven AI drivers with distinct pace, aggression, mistakes, racing lines, and overtaking behavior
- Detailed procedural car bodywork with suspension, halo, wings, sidepods, wheels, paint finishes, numbers, and team liveries
- Procedural city façades, balconies, yachts, palms, grandstands, Armco barriers, curbs, banners, and dynamic lighting
